 projet : Prédiction du risque de crédit par Machine Learning

Je viens de finaliser un projet de Data Science appliqué à la finance, visant à prédire si un client peut se voir accorder un crédit.

🎯 Objectif :
Améliorer la prise de décision dans l’octroi de crédit et réduire les risques financiers.

🧠 Approche :

* Classification binaire (accepté / refusé)
* Modèles testés : Logistic Regression & Random Forest
* Prétraitement complet des données (nettoyage, encodage, normalisation)
* Gestion du déséquilibre des classes
* Évaluation avec Precision, Recall, F1-score, ROC

📊 Résultats :

Deux modèles ont été testés : Logistic Regression et Random Forest.

Random Forest a été retenu car il offre de meilleures performances,

notamment en recall sur la classe des clients acceptés.

Le modèle Random Forest obtient :

✔ 96% d’accuracy

✔ 89% de recall sur les clients acceptés

✔ 95% de précision
